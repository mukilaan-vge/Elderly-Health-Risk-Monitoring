Add this import near the other FastAPI imports:

from fastapi.staticfiles import StaticFiles

Then, after all existing API routes have been declared in src/api/app.py, add:

FRONTEND_PATH = resolve_path("frontend")

if FRONTEND_PATH.exists():
    app.mount(
        "/dashboard",
        StaticFiles(directory=FRONTEND_PATH, html=True),
        name="dashboard",
    )

The frontend will then be available at:
http://localhost:8000/dashboard/

No CORS configuration is needed because the dashboard and API use the same origin.
